You are a senior Java backend engineer and Spring Boot architect.

Build a complete, production-ready REST API backend for a **Cosmetics E-Commerce Application** using **Java + Spring Boot**.

The project will be used for selling cosmetics and beauty products such as skincare, makeup, haircare, fragrances, beauty tools, etc.

Use the following technologies:

* Java 21
* Spring Boot 3.5.x
* Maven
* Spring Web
* Spring Data JPA
* Spring Security

* MySQL
* Hibernate
* Bean Validation
* Lombok
* Spring Mail
* Jackson
* OpenAPI / Swagger
* JUnit 5
* Mockito

Use clean, maintainable, production-quality code.

Follow layered architecture:

Controller → Service → Repository → Database
